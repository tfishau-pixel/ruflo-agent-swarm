# Rules — vault/04 Resources/ (provenance-critical)

- Source material is **evidence**. Never replace, trim, or "clean up" source
  content with a summary. A summary may be added as a clearly-marked layer
  above the source; the original text stays intact below it.
- Preserve provenance metadata where available: title, author, source, URL,
  original date, date accessed (see `vault/07 Templates/Source.md`).
- Never edit quoted external material except to fix obvious import/formatting
  noise, and say so when you do.
- When citing a resource elsewhere, link to it; do not copy chunks into other
  notes (creates divergent copies).
- Deleting or overwriting anything in this folder is a DESTRUCTIVE action:
  explicit approval required, and prefer moving to `99 Archive/` instead.
