# Weekly Review

**Purpose:** a useful altitude check, not busywork. Read-only by default;
fixes happen through the other skills afterwards.

## Workflow

1. Projects: for each README in `01 Projects/`, note status, whether Next
   Actions moved since last review, and staleness signals.
2. Actions: collect overdue/long-unmoved `- [ ]` items across READMEs.
3. Inbox: count and age of `00 Inbox/` items; flag a growing backlog.
4. AI review: list `06 AI Workspace/Pending Review/` awaiting the owner.
5. Decisions: significant decisions this week not yet captured.
6. Connections: obvious relationships between this week's daily notes /
   new material and existing projects or knowledge that were missed.
7. Skim this week's daily notes for unharvested value (offer `/daily-review`).

## Contract

- Level: READ. Propose actions; execute only what the owner picks
  (each via its own skill: process-inbox, project-update, etc.).

## Output

One screen, most-important-first: 🟢 moving / 🟡 stalled / 🔴 needs a
decision · top overdue actions · backlog counts · suggested next steps
(max ~5). Do not list healthy things at length.
