# Project Brief

**Purpose:** assemble just enough context to work competently on a project —
never the whole vault.

## Workflow

1. Read `vault/01 Projects/<Project>/README.md`.
2. Search the vault for the project name and its key terms (titles first).
3. Follow only the links the current task makes relevant (Key Notes, recent
   Decisions, open-question references). Stop when additional reading stops
   changing the picture.
4. Note unreviewed material in `06 AI Workspace/` touching this project —
   include it clearly marked as unreviewed, never as fact.

## Contract

- Level: READ. No writes.
- Do not read entire folders; follow links and search hits only.

## Output

A compact brief: outcome · current status · next actions · decisions that
constrain the work · open questions · links (paths) to the notes that matter
for the task at hand · anything contradictory or stale spotted on the way.
